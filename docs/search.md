# 検索

ログイン後、ヘッダーの「検索」から `/searches` を開きます。名前によるユーザー検索、管理者のみメールアドレス検索、投稿内容・投稿者ID・開始日・終了日の組み合わせに対応します。終了日の全時刻を含みます。未有効化ユーザーとその投稿は表示しません。検索条件はページ切り替え時にも維持されます。

REST規約に合わせ SearchesController#index に検索対象を集約しています。

部分一致は `%term%` のため通常のB-treeインデックスでは高速化できません。既存の投稿者・投稿日時の複合インデックスを使い、20件単位のページングと関連の先読みでクエリ数を抑えます。RSpecで25件の結果を20件に制限し、ユーザー・画像アクセスを含むSELECTが5件以内であることを検証します。大規模運用時は実データのEXPLAINを基にPostgreSQLのpg_trgmを検討してください。
